# tasks.md — 상세 작업 계획서

`basic-plan.md`(무엇을, 왜)와 `CLAUDE.md`(어떻게)를 실행 단위로 풀어 쓴 문서입니다.
작업을 끝내면 `[x]`로 바꾸고, 새로 생긴 작업은 해당 단계에 추가합니다.

## 표기

| 표기 | 뜻 |
|---|---|
| `[ ]` / `[x]` | 미완료 / 완료 |
| **[시안]** | 디자인 결정. 시안 2~3개를 제시하고 선택받은 뒤 진행 (CLAUDE.md 규칙 1) |
| **[확인]** | 사용자의 검토·승인·답변이 있어야 다음으로 넘어감 |
| **[자료]** | 사용자가 제공할 자료가 필요함 |
