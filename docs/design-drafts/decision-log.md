**선택: A. Quiet Dossier + 상단 메뉴 + 중앙 정렬** (시안 `g1/a3.html`에 A′의 중앙 정렬을 더한 형태)

**확정한 것**
- 차가운 무채색 바탕, 얇은 선의 카드, 포인트 색 1개(슬레이트 블루 계열)의 차분한 인상
- 고정 왼쪽 사이드바(사진, 이름, 직함, 소속, 연락처)와 카드형 섹션
- 본문 위 고정 상단 메뉴: 섹션 앵커 이동, 현재 섹션 밑줄 표시, 오른쪽 끝에 언어·테마 전환. 사이드바의 섹션 목차는 두지 않는다.
- 사이드바와 본문을 묶어 화면 가운데 정렬 (넓은 화면에서 오른쪽 빈 공간 제거)
- 기본 테마는 시스템 설정을 따르고, 수동 전환은 기억한다 (2.1 답변)

**이유**
- 사용자가 세 시안 중 A의 정제된 인상을 가장 선호했다.
- 섹션이 많고 긴 페이지라서 현재 위치를 보여주는 상단 메뉴가 필요하다는 데 동의했다.
- A′와 비교한 결과 가운데 정렬이 넓은 화면의 균형을 개선했다.

**이후 Gate로 넘긴 것**
- 서체: A는 Geist, A′는 참고 사이트의 역할 분리(Space Grotesk / Public Sans / IBM Plex Mono). G2(3.1.1)에서 2~3안으로 결정한다.
- 색: 포인트 색과 다크 팔레트는 G2(3.1.2)에서 결정한다.
- 경력 궤적 표현(A의 가로 타임라인, A′의 칩, C의 세로 축)은 G3(3.1.5)에서 결정한다.
- 대표작 카드의 이중 테두리(카드 안의 카드)는 G4(3.2.1)에서 해소한다.
- 분야·역량 태그에 국문 값이 없어 국문 화면에서도 영문으로 표시된다. 단계 5.7 UI 번역에서 처리한다.
