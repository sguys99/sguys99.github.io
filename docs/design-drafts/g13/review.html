① 관람 동선 (새 섹션 Visitor journey, Architecture 앞)

A. 로비 평면 개념도 + 단계 목록

세미나 개념도를 정리한 평면 위에 1·2 → 3 → 4 → 복귀 동선. 공간감이 가장 잘 전달되고 아래 단계 목록이 모바일에서도 읽힘. 세로로 가장 김

B. 시나리오 레인

4단계 × 이동·음성·제스처·관람객. 로봇이 여러 기능을 동시에 맞물려 수행한다는 점(통합의 난이도)이 드러남. 공간 정보는 없음

C. 노선도

호출 → 4단계 → 복귀를 한 줄로. 가장 간결하고 가벼움. 정보량은 가장 적음

② 아키텍처 (기존 Architecture 표 자리)

A. 4구역 회로도

현장 / 현장 서버 / 로봇 온보드 / 외부. SCM 회로도와 같은 문법이라 사이트 일관성이 높음. 비상정지가 판단 계층을 돌아 전신 제어로 가는 경로가 강조색. 노드 16개로 촘촘함

B. 계층 띠

사람 → 서버 → System 2 → 버스 → System 1 → 하드웨어를 위에서 아래로. "판단과 제어 분리"가 가장 잘 보이고 정돈됨. 데이터 흐름(누가 누구와 통신)은 생략

C. 배치와 경계

로비 / 현장 서버 / 외부망의 물리 배치와 네트워크 경계. 노드 8개로 가장 쉬움 + 설계 원칙 3줄. 소프트웨어 내부 구조는 없음 (C 선택 시 B와 조합 권장)

③ 안전 체계 (새 섹션 Safety, Architecture 뒤)

A. 접근 거리 원 + 3경로 정지 신호

왼쪽 1m·0.5m 원, 오른쪽 세 트리거 → 안전 채널 → 전신 제어 (LLM 계층 우회). 두 가지 안전 장치를 한 장에. 가장 시각적

B. 거리 눈금 + 비상정지 표

접근 거리를 가로 눈금으로, 3경로를 표(조작 주체·정지 동작·비고)로. 정지 동작 차이(0 토크 vs 선 채로)가 가장 정확히 읽힘. 모바일에서도 표가 쌓여 읽힘

C. 3중 방호

관제 ⊃ 제어 ⊃ 감지 ⊃ 관람객의 겹 구조. 착수보고서의 "센서·제어·관제 3중 방호" 메시지. 구체 수치와 경로는 글자로만

④ 기종 비교 (Approach 섹션 안 소제목, 결정 표 아래)

A. 비교표만

6개 항목 G1 vs X2 Ultra, 선정 열 강조 + 선정 이유 한 줄. 가장 가벼움

B. 선화 일러스트 + 비교표

직접 그린 선화로 두 기종의 차이(얼굴 화면·목 관절·LED)를 짚음. 저작권 걱정 없고 사이트 톤과 맞음. 실물감은 약함

C. PPT 제품 사진 + 비교표

세미나 9쪽의 제조사 이미지를 그대로 사용 + 출처 표기. 실물감이 가장 큼. 공개 저장소·사이트에 제조사 이미지를 싣는 이용 조건 확인 필요, 다크 모드에서 흰 사각형이 도드라짐
